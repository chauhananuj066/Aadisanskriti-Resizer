🖼️ Adisanskriti-Resizer - User Guide
------------------------------------------

📌 What it does:
This tool resizes your images to 1200 x 900 pixels and saves them as high-quality JPG files.

✅ Features:
- Drag and drop or select multiple images
- Automatic resize to 1200x900
- Easy-to-use, beginner friendly
- All resized images saved in "output" folder

📦 How to Use:
1. Double-click on `Adisanskriti_Resizer.exe`
2. Click the "Select Images" button.
3. Choose one or more images (PNG, JPG, JPEG, BMP, WebP).
4. The app will resize all images to 1200x900 and save them in the `output` folder (in the same directory).

🗂️ Where are the resized images?
Check the "output" folder. It is created automatically.

📁 Supported Image Formats:
- PNG
- JPG / JPEG
- BMP
- WebP

📋 Notes:
- Only image files are processed.
- Each image will keep its original filename, but the format will be saved as `.jpg`.
